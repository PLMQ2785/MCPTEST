# ⌨️ 키보드 입력 테스트 프로그램

심플하고 직관적인 키보드 입력 시각화 프로그램입니다. 키보드 버튼을 누르면 실시간으로 시각적 피드백을 받을 수 있습니다.

## 🎯 주요 기능

- **시각적 키보드 표시**: 실제 QWERTY 키보드 레이아웃 구현
- **실시간 입력 감지**: 키를 누르면 해당 버튼이 즉시 반응
- **입력 정보 표시**:
  - 마지막 입력 키 표시
  - Key Code 정보 제공
  - 누적 입력 횟수 카운팅
- **입력 기록**: 최근 15개의 입력 기록 유지
- **심플한 디자인**: 하얀색 기반의 미니멀한 UI/UX

## 📋 사용 방법

1. `keyboard-test.html` 파일을 웹 브라우저에서 열기
2. 키보드의 아무 키나 눌러보기
3. 누른 키가 시각적으로 표시됨을 확인
4. 기록 초기화 버튼으로 입력 기록 리셋 가능

## 🛠️ 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript (라이브러리 없음)

## ✨ 특징

- 반응형 디자인
- 실시간 피드백
- 사용하기 쉬운 인터페이스
